Offline Chinese speech recognition uses Vosk API and vosk-model-small-cn-0.22.
Project: https://github.com/alphacep/vosk-api
Model: https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip
License for Vosk and this model: Apache License 2.0.
Vosk Copyright Alpha Cephei Inc. and contributors.

Vosk's Android bridge uses Java Native Access (JNA).
Project: https://github.com/java-native-access/jna
JNA is distributed here under its Apache License 2.0 option.
Full license: APACHE-2.0.txt in this directory.

The model is copied to app-private storage on first use. Microphone audio and
transcriptions are processed on the device; no audio is sent to an ASR server.
Sending the resulting text to the AI chat remains a separate user action.
