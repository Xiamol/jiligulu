本轮用户明确授权：首页下拉刷新信箱、单张大卡片分类设置页、删除初次见面声音设置、统计柱图/日期/收支颜色/占比、悬浮窗截图识别、聊天选图识别。语音不再继续，版本暂保持 0.5.6，本地 release 试用，不自动发布 GitHub。

## 行为

- 公告原来每进程冷启动联网一次，前台每分钟仅更新本地有效期，不是联网轮询。新增首页下拉刷新；刷新更新内容但不安排第二次自动弹窗，失败保留缓存并提示，远端空列表可撤下公告。
- 设置采用单张大卡片，上方日常/提醒/数据/关于切换分类；保留全部原有数据/提醒配置，移除声音与重看初次见面入口。
- 统计使用固定金额轴、44dp 日期间距、24dp 柱宽，横滑浏览；日期按钮在每日收支右侧。选中使用紫色、背景轨道、渐变强调和文字，不只靠色差。全局收入绿、支出珊瑚红并保留正负号。分类占比和预算使用占比常态展示。
- 聊天「添加账单图片」调用系统照片选择器，无全相册权限。预览后点击「识别并填入」才调用 DeepSeek 图片接口；文字可改，手动发送后进入原草稿确认流程。图片不会自动入账，不保存为账单永久附件；取消或成功识别后清理当前缓存图片。
- 设置→悬浮记账开启阿噜浮球，需要系统悬浮权限。拖动移动，点击请求单次截屏授权，长按或通知关闭。截图回到聊天预览，与选图复用同一识别链路。系统限制截屏的页面可能是黑屏，不能绕过。未做常驻后台录屏、后台自动上传。

## 维护入口

- `data/announcement/AnnouncementRepository.kt`：刷新互斥、缓存和弹窗会话。
- `ui/stats/charts/CashFlowBarChart.kt`：横滑坐标图；`StatsViewModel.kt` 预算百分比。
- `ui/capture/ImageBillImport.kt`：有界图片读取、EXIF 方向、压缩和可取消网络请求。图片解释使用独立提示，不改变普通聊天缓存前缀。
- `ui/capture/ImageAttachment.kt`：照片选择、预览、失败重试、取消与文字回填。
- `ui/capture/FloatingCaptureService.kt`：用户开启的前台悬浮服务；`CapturePermissionActivity.kt` 使用独立透明任务，避免授权返回后截到本 App。
- `ui/capture/ScreenCaptureService.kt`：mediaProjection 前台服务、一次帧截取、12秒超时、释放资源。授权令牌不保存不复用。
