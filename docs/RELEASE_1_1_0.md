# 叽里咕噜 1.1.0 · 小生活，慢慢收好 🪻

这次把 1.0.0、1.0.1 以来的更新一起带来：看账更方便，阿噜更记得你，照片、棋桌和好运小角落也更顺手了。

## 账本与统计

- 主导航调整为**账本、统计、小窝**；统计图内直接切换 5、7、10 天或整月，选择会记住。柱图跟着手指移动，月边界先回弹，短时间内再次同向滑动才跨月；箭头按当前周期前进，日期选择需确认后定位。
- 整月折线保留实际支出与日均参考；分类圆环可查看分类明细，预算下可切换月/年已过比例。
- 对话可按日期、关键词与分类检索完整账本。汇总使用全部匹配账单，不再只靠最近几天的上下文回答；普通聊天仍可选择带入 3、7、30、90 天或全部范围。
- 每笔聊天草稿都能独立夹生活照片，收起时也可操作，确认后关联到账单和纪念册。夹生活照不等于发送给 AI 识图；草稿展示更集中，识图原文仍保留。
- 长按「待定」可预览批量分类建议、勾选账单，再确认创建或复用分类；未选账单保持原样，金额、时间与附件保留。支付宝和微信的扫码、付款码入口并排放在账本页。
- 补齐水果、蔬菜、通讯、运动、旅行与礼物等预设分类，保留同名自定义分类；一次补齐后不会反复添加你已删除的预设。

## 设置与阿噜的记性

- 设置按外观、互动、提醒、数据、关于分组，支持标签点按和左右滑动，各页记住滚动位置，说明收进问号。
- 阿噜可在本机记下你明确说出的身份、学业和喜好，也理解有上下文的简短回答；不会把花销、识图文字或阿噜的猜测当作个人资料。记忆可关闭、更正或删除，旧聊天里的明确资料可先预览、勾选再补记。
- DeepSeek 与自定义 OpenAI Chat Completions 兼容服务分别保存地址、模型与密钥，可按服务能力配置识图等选项。AI 功能需要联网和可用的服务配置；当前供应商可在「设置 → 数据 → AI 服务」查看。
- 恢复默认 DS 官方 API：新安装或清空个人 DS Key 后可使用默认配置，填写个人 Key 时优先使用个人配置；自定义供应商不受影响。
- 移除 API 花费统计、计价设置与用量记录；升级清理废弃统计数据，保留账单、聊天、个人记忆和供应商配置。

## 小窝、照片与心事

- 写给阿噜的心事可以收到 AI 回信。来信先显示到达提示，点「去邮局」进入完整场景，再从收件箱打开信件。
- 转盘、邮局、纪念册和愿望瓶按进入路径逐级返回；打开转盘纸条后再关闭，原页面与页签仍在。
- 整理图片缓存、照片处理与海报生成，移除闲置素材；保留已有照片、账单与信件，减少重复解码和临时文件。

## 坐下来玩一会儿

- 棋友会集中选择棋种与对手，可编辑昵称和相册头像。棋桌显示双方名片、执子与回合状态，等待开局时收起尚未开始的时钟。
- 五子棋人机对局优化战术应手；离开页面、暂停或换局时取消旧计算，避免过期落子。
- 同屏对局直接按所选棋色悔棋；附近与房间对局仍需对方同意，并支持双方协商和棋。临时切到后台或断线可在同一进程内获得最多 5 分钟恢复窗口，保留原棋色与棋盘；明确退出会关闭房间，系统结束进程后暂不支持续局。
- 房间码支持选择、逐字删除、替换与输入法组合输入；分享邀请、返回棋友会及棋局结算更清楚。两位棋友都需升级，附近对局要在同一局域网；互联网房间还受房间服务与网络条件影响。
- 落子、翻信、转盘和小算盘的音效反馈更完整，跟随媒体音量与应用音效开关。修复象棋底部阿噜装饰被错误隐藏的问题。

## 好运小角落

- 直接点击转盘即可旋转，结果和操作位置更稳定；增加小黄历、星座与每日小任务，阿噜换上小先生的长衫和布帽陪你玩。
- 小六壬先写想问的事，再选当前农历月日时或三位灵感数字。解读先给直接结论、短原因和实际建议，三宫详情按需展开；已有合格解读可重看，无需再次请求。
- 改命会显示大吉章，并将这次解读切换为阿噜的鼓励版，原解读仍可查看；回执随当前课保存，不会套到其它问题，小六壬与星座各自记录次数。

## 显示与悬浮记账

屏幕刷新率支持系统、60、90、120 Hz，实际档位由设备和系统决定。悬浮图标可调大小、记住位置；App 内拖动或页面滚动时交接背景折射，静止时没有持续采样。App 外保持透明材质，只有主动截图或准备截屏时才申请系统共享授权。悬浮常驻通知可从设置直达系统对应类别；邮件、喝水提醒与主动截屏类别各自独立。

## 安装与数据

版本 **1.1.0 / versionCode 27**。请直接覆盖安装，**不要先卸载**；1.0.0、1.0.1 和 1.0.13 用户均可更新。包名、签名与 Room v6 数据库继续沿用，账单、照片、对话和设置保留。

使用方法在「设置 → 关于 → 阿噜使用手册」。数据仍保存在本机；本次没有增加跨设备同步或独立整库备份。小六壬与运势是娱乐玩法，实际决定仍由你来做。

1,028 项单元测试通过，release 构建与 lint 通过。Android 模拟器核对关于页、1.1.0 手册、覆盖安装，以及默认配置的首装、清空个人 Key 后的官方在线回复；个人 Key 优先与自定义供应商隔离有回归测试。真实 Key 未写入公开源码、文档或提交；默认配置通过本机构建注入，安装包内置 Key 可被提取。
