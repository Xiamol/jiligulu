# 1.0.2 本地验收记录

验收日期：2026-10-08（Asia/Tokyo）。版本名 1.0.2，版本码 15。此包用于本地测试；GitHub App 最新公开版本仍为 1.0.0。

## 统计和设置

- 设置提供“10 天紧凑”和“整月压缩”，选择立即持久化。10 天窗口连续跨月；整月窗口左右移动切换月份，支持跨年与未来空月份。
- 返回统计自动选中当天。默认月份、日期、十天窗口共用午夜日期源，修复月末跳回旧月第一天的竞态，并取消默认月份的每分钟轮询。
- 日期箭头改用居中矢量图标；移除图头“元”，柱图/折线切换靠右；整月首末日期标签在图内定位，避免裁切。
- 设置分为外观、互动、提醒、数据、关于。真实 HorizontalPager 支持跟手左右滑动与标签点按；各页独立保存滚动位置，离屏弹窗与阿噜动画停用。
- 删除音效试听。说明收进对应问号；隐私、授权与耗电条件仍可完整查看。名字与 API Key 保留各自的编辑保存窗口。

## 玻璃与耗电

- 屏幕刷新率提供系统/60/90/120 Hz，仅请求本应用窗口的支持档位，系统省电限制优先。默认系统策略不再强制最高刷新率。
- 玻璃采样目标提供 15/30/60/120 次每秒，默认 30，即选即存；同时作用于应用内与用户本次授权后的全局模式。修改速度不会启动共享授权。
- 应用内 PixelCopy 按实际画面/位置变化工作，移动先重投影可用的缓存，复制结果再次按当前坐标绑定；静态时没有持续复制计时器。
- 全局采用持久 ImageReader Surface，处理最新画面、每次只有一帧在处理；移除拖动暂停与松手等待 300 毫秒、固定 12 帧限制及重复挂接 Surface。运动历史排除自身及布局延迟区域，避免图标被重复采入。
- 图像缓冲和 Shader 缓存复用，ROI 尺寸固定，像素比较移出主线程。隐藏、锁屏、关闭共享或画面不可见时暂停/释放采样；相同像素避免上传纹理与重绘。
- 应用内与全局共用完整透镜光学，系统窗口模糊半径为 0。**全局中心由外围可信像素近似重建，无法准确恢复被图标遮住的文字与细节；应用内是真实背景。** 详见 [光学实现和平台边界](global-glass-optics-2026-10-07.md)。
- 高档采样是目标，实际速度受设备、来源画面和处理速度限制，增加耗电。系统不允许悬浮窗的页面仍可能隐藏图标。
- 阿噜呼吸改为有限动画；离屏账本不再换语录。未来来信只在前台等待实际下一到期时刻，没有 30 秒轮询；空信箱与后台挂起。

前一轮相同模拟器账本静置采样：旧包 90.652 秒 / 8079 次重绘（89.121 次/秒），优化包 78.486 秒 / 112 次（1.427 次/秒），约减少 98.4%。这是应用窗口重绘计数，**不是屏幕物理 Hz 或手机 mAh 实测**。该采样在本轮可调高档全局采样加入之前完成，不能当作全局 120 档的功耗结果。

## 返回、棋友与小互动

- 棋友会统一选择棋种和对手，增加昵称与头像名片。顶部席位显示头像、名字、执子和回合状态；开局中央先行提示，移除底部重复微文案。
- 棋盘返回、收桌回棋友会；对手明确离开时保留棋盘并提示。房间分享提供 HTTPS 邀请入口，严格检查棋种与房间码；重复打开自己的有效房间邀请不会销毁房间。双方需更新到新握手版本。
- 转盘、未来邮局、纪念册、贴纸与愿望瓶按进入路径逐级返回。转盘的纸条是覆盖弹窗，父转盘指针、任务与页签保留。
- 纸条标题居中避开花边，动作位置固定；愿望册全屏固定架子，三种瓶子弹窗统一操作布局。场景热点去除按压矩形变色。
- 转盘新增本机日期与星座的小黄历、20 个小任务、每日阿噜盖章表情。属于趣味玩法，不使用付费 API 作运势预测。
- 首页删除空闲状态“咕噜在这里”，修复开头逗号和重复逗号，语录增至 100 条。
- 对话记忆只接受用户亲口说的身份和喜好，拒绝从消费/OCR/转述猜性别年龄；可查看、修改、删除、清空或关闭。最多 12 条，随已有对话请求学习，不加额外付费轮次，动态上下文不污染稳定前缀。年龄/学业/职业保留记录时间，避免把旧资料当作当前事实。

## 尚有外部条件的事项

- MuMu 已安装旧 1.0.1，其 NSD 注册和搜索实际返回系统 mDNS 错误 501。新增有限重试和诊断不能替代模拟器的可互通网络；10.0.2.x 虚拟网络并不证明与手机处于可发现的物理局域网。
- 流量/复杂 NAT 的远程对局仍需要稳定 TURN 中继；部署材料在 `server/chess-relay/`，本轮没有取得新的部署账号或完成跨运营商实机验收，不能承诺任意外网都能连接。
- 邀请支持页已在独立 `room-invites` 分支发布并验证匿名 HTTP 200。浏览器入口不等同于房间连接成功，部分聊天客户端需使用系统浏览器打开。

参考：[Android 模拟器网络](https://developer.android.com/studio/run/emulator-networking-address)、[MediaProjection](https://developer.android.com/media/grow/media-projection)。
