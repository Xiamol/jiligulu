# 叽里咕噜 v0.5.6

### 对话记账与闲聊

- 改善多轮聊天的在线回复稳定性，保留原有聊天记忆，不需要清空历史。
- 新草稿直接展开，可修改金额、名称、分类和时间；主动收起或离开聊天再回来后折叠。
- 未确认时不再提前声称“记好了”；确认入账后只发送一条结果回复。
- 新消息、加载气泡变成回复或草稿时自动跟到底部。
- 修复取消过的操作卡复活、重复执行、仅修改名称或时间失败等问题。

### 喝水提醒

- 重做提醒调度，支持开机、覆盖更新及重新进入应用时恢复。
- 到点后阿噜保留拿杯姿态，完成喝水动画后再恢复普通状态。
- 补充通知、准时提醒、自启动和后台运行设置指引。

部分手机即使亮屏也可能冻结后台应用；请允许叽里咕噜自启动和后台运行。系统省电与权限限制仍可能延迟提醒。

### 设置与数据管理

- 可以通过聊天生成喝水设置调整卡、清空回收站确认卡，以及检查更新入口；改设置和删除数据必须确认。
- 增加《阿噜使用手册》和清空历史对话功能；清空聊天保留账单及未入账草稿。
- 修复恢复账单的分类归属，统一分类图标兜底与统计显示。
- 自动更新在首次进入及从后台返回时实际检查，成功后更新“上次成功检查”时间。

### 安装

本次只提供 **release 安装包（非 debug 构建）**，沿用已有签名。请直接覆盖安装，不要先卸载；升级包含保留原账本、分类、预算和聊天记录的数据库迁移。

验证：269 条自动测试通过；静态检查无错误。在线聊天另做了真实接口对照及连续对话验证。第三方 AI 服务仍可能偶发失败。
