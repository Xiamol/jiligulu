# 阿噜的小信箱

1.3.16 的更新来信邀请你免费答题领取「比奇堡晴日」，也介绍了聊天拍一拍、生活圈互动时间、联机棋桌和统计日历。点阅读页左下角的小钟，可以在目录里挑一封当前或往期来信。[本次公告](../content/announcement-release-1.3.16.json)

## 当前公告来源

应用通过当前电脑服务的 `/v1/announcements` 获取公告，读取请求遵循已有联网选择和设备签名校验。管理员从本机管理台发布、查看或撤下；公告不经过AI。

GitHub的 `announcements` 内容分支与旧版本静态文件属于历史机制，**不再是当前应用默认公告源**。仓库中的版本化JSON是公开文稿留档，修改它本身不会向手机发送公告。

新公告使用新的ID，保留已有来信的阅读与屏蔽记录。仅修正错别字时应保留原ID；不要重发同一内容以反复打扰用户。发布结果不明时先查询列表，避免重复提交。

## 手机上怎么看

- 打开首页的小信箱，可主动查看当前有效来信；联网冷启动或刷新时更新内容。
- 每次冷启动最多自动弹出一封未屏蔽的有效来信，更新提示优先，不叠加两个弹窗。
- “关闭”只对当前会话生效；“这条不再弹出”按公告ID保存，新的来信不受影响。
- 普通页面切换、后台返回或界面重建不会重置本次会话。断网或拉取失败不阻塞使用，已有有效缓存仍可查看。
- 公告只有纯文本和换行，不执行HTML或脚本；最多20封，单封标题80字、正文6000字，完整内容不超过64KiB。

维护者在本机后台发布正文，确认服务端已保存后再记录对应ID。旧来信可作为历史保留，但不能把旧版本号、过期测试内容或旧下载链接误写成这次更新。
