## 文件格式

```json
{"schemaVersion":1,"announcements":[]}
```

单条示例见 `content/announcements.example.json`。`id`、`title`、`body` 必填，其余字段可省略。

- `id`：80 字符以内，英文、数字、点、下划线或连字符，必须唯一。**新公告换新 id**；仅改错别字保留 id，已屏蔽的用户不会因此又被弹窗打扰。
- `title` 最多 80 字符，`summary` 最多 160 字符，正文 `body` 最多 6000 字符；正文支持换行，按纯文本展示。
- `emoji`：短的节日表情，可省略；`priority` 越大越靠前，默认 0。
- `startsAt` / `endsAt`：可省略。填写时需带时区，如 `2026-09-25T00:00:00+08:00`。起始时间包含，结束时间不包含。
- `enabled:false` 可暂时撤下。清空 `announcements` 可撤下所有公告；不要删除文件或写坏 JSON，否则离线容错会继续保留缓存中的有效公告。
- 文件不超过 64 KiB，最多 20 条。重复 id、非法日期、格式错误或超限会拒绝本次更新，保留上一份有效缓存。

## 展示规则

- 每次冷启动最多自动弹出一条有效、未屏蔽的公告；优先展示更新提示，两个弹窗不叠加。
- “关闭”只对当前进程会话生效；再次冷启动仍可弹。
- “这条不再弹出”按 id 持久化；首页仍能主动查看这条，新的 id 不受影响。
- 首页小信箱可查看所有当前有效公告，正文弹窗可切换上一封/下一封。
- 页面切换、后台返回、Activity 重建不重置公告会话。过期公告从首页及弹窗移除；后台返回不当成新的冷启动。
- 拉取失败不阻塞启动；已有缓存仍按有效期使用。没有内容时首页显示空信箱，点击可以打开空信笺说明，不会假装有已发布公告。

## 本轮语音范围

**最新状态（2026-09-24）：用户已选择小型离线模型，当前入口已改用 Vosk 中文小模型，release 试用包构建及 8 个相关用例通过，等待真机试说。以下系统语音描述为排障历史，已不再使用该入口。构建及验收见 [离线语音试用](OFFLINE_VOICE.md)。**

聊天输入区增加麦克风切换：按住说话，松开识别，文字回填到原输入内容后，可修改再点发送。移出按钮或离开页面取消。没有自动发送/自动入账；不保存录音文件。

2026-09-24 补充：主动选择的键盘/语音模式保存到 DataStore，退出聊天或冷启动后恢复。语音转写后临时进入文字编辑，不覆盖用户的语音偏好；发送后恢复该偏好。初次安装默认键盘，旧版没有保存过的选择无法反推。

采用 Android 系统 SpeechRecognizer。最初请求显式指定中文；2026-09-24 为诊断 vivo 的错误码 5，改为最小请求，只保留 free_form 语言模型，使用系统默认语言，取消可选语言/中间结果/候选数参数。首次只申请录音权限，授权后需要重新按住才开始录音。录音最长约 30 秒，等待识别结果限时 12 秒；后台退出会取消并销毁识别器，过期回调不回填文字。

系统服务可能联网。没有识别服务、中文资源不支持或权限拒绝时明确提示并保留键盘输入。本轮未接第三方付费转写，也未打包离线语音模型；2026-09-24 已确认用户手机的当前系统方案无法启动识别，不能把语音功能标记为真机可用。

### 2026-09-24 真机语音问题

麦克风权限已确认授予；手机默认识别组件是 `com.vivo.ai.copilot/.framework.wakeup.CopilotRecognitionService`。原请求六次在 10–31ms 内返回 `ERROR_CLIENT=5`，且 `ready=false`、`stopRequested=false`，并非用户松手太快或 App 提前停止。系统未提供可启动的 ACTION_RECOGNIZE_SPEECH 页面。本次只记录错误码、服务名称及阶段，不记录识别正文或录音。

同签名诊断包与最小请求兼容包均已通过 `adb install -r` 覆盖安装，未清数据。用户确认最小请求仍返回错误码 5，因此停止重复尝试当前系统接口。下一步等待用户在离线模型、独立云转写、暂缓语音之间选择；未擅自切换到手机中其他应用的识别服务。

输入模式记忆及空信箱点击反馈已完成，2 项相关 UI 用例分别通过；其中模式重进用例需等历史加载后按钮可点击再操作，已修正测试等待。没有重跑全套旧功能。
