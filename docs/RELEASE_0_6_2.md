# 叽里咕噜 v0.6.2 · 小账本，又顺手了一点 ♡

聊天记账、截图识图，再让阿噜陪你翻翻每天的小账单。记录可先修改，确认后才入账。

这次主要把统计页和滑动体验重新整理了一遍：

- 📊 **统计更紧凑**：五天柱图自适应宽度，柱顶直接看金额；日期区间跟着柱图滑动，点下拉箭头挑日子。
- 🍴 **分类一眼明白**：左边圆环、右边分类，点一次高亮，再点同类打开小账单窗口；分类多时也能滚动查看。
- 💜 **预算轻轻看**：百分比和进度条替代预算圆环，点箭头就能调整。
- 💌 **小窗更可爱**：日历和信笺缩小，长内容可以滑着读。
- 🫧 **滑动更自然**：边界回弹，分类列表支持再次同向滑动带动外层；修复账本切页时闪动和吸附位置变化。

仅提供 Release 安装包。请直接覆盖安装，保留本机账单和聊天记录。

## 认识一下叽里咕噜

聊天记账、图片识别、悬浮截图、按日账本、收支分类和预算进度，装进一个淡紫色的小账本里。阿噜还会陪你聊聊天、提醒喝水。
