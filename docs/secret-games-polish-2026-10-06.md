# 秘密棋桌与日常细节整理

日期：2026-10-06。状态：a4 功能逻辑包的统一构建、566 项测试及下述原生回归已通过；最终 df 样式包 Release 构建与双端安装启动通过。最终原生图册和 source commit 以交付目录的 `manifest.json` / `verification.json` 为准。

## 本轮变化

### 游戏界面与结果

- 秘密纸条、棋桌操作和结果使用新生成的木质面板素材；用户追加调整后采用 V2 浅灰米、低饱和细木纹，收窄原先过重的橙色边框与纹路。界面采用分片缩放保留花叶、黄铜钉与布角，文字和操作由 Android 原生组件绘制。
- 转盘改为原生二维 Canvas 绘制，低饱和六个扇区、平面轮缘与固定指针，没有倾斜透视或复用 V1 栅格立体转盘；六组、八种结果及原有旋转/抽取玩法保持不变。
- 五子棋、象棋结束后保留明确的胜、负、和结果牌，直到再来或离开。约 3.2 秒的庆祝特效是附加反馈，特效结束不会把结果牌一起收走。
- 五子棋胜利连线由真实棋盘计算；象棋仅按终局证据区分将死、困毙、擒将，以及条件严格匹配的重炮、闷宫。不用最后移动的棋子猜杀法名字。
- 胜负按实际玩家执色判断，不再把历史枚举名 `CPU_WON` 等同于“阿噜赢了”。可见文字和棋盘无障碍描述保持一致。

### 执色、存档和本地人机

- 新本地对局分配执色；抽到后手时电脑先行。再次对局交换执色，CPU 落子、玩家点击、悔棋和棋盘朝向都跟随该字段。
- 存档记录执色及是否已经分配座位。已分色但尚未确认象棋思考时间的空盘，退出再进也保持执色；旧档缺字段时保留旧版红方/黑棋先手约定。
- 恢复棋局先暂停，保留合法历史和象棋思考提醒。终局恢复不重播庆祝与胜负声；计时是提醒，时间到不判负。
- 本地人机悔棋退回最近一次玩家可以重新决定的局面，执后手时不会悔掉电脑的首次开局。加载残局时，题目行棋方交给玩家，避免电脑替玩家解题。
- 象棋使用项目内 Kotlin 本地规则和搜索：迭代深化、将军延伸、静态战术搜索、着法排序、置换表与限时取消。普通搜索默认约 700ms，调用方使用后台调度，过时结果不会写回新棋局。
- **没有接入 Pikafish，也不调用 DeepSeek 下棋，不产生模型调用费用。** 参考常见搜索算法增强既有实现，没有复制或分发其他引擎的代码、二进制或权重；不宣称职业级或无敌。

### 约棋与房间生命周期

- 「附近」通过同一 Wi-Fi 的服务发现寻找棋友，互联网房间通过房间码建立连接；两条入口与状态分开。
- 房间码可以自行填写，也可生成；开始对局需要对方确认。房间状态与实际连接绑定，不将过期发现或迟到回应当作当前邀请。
- 联机终局保留 30 秒结果窗口。双方同意再来时交换执色并进入新局；拒绝或时间结束则关闭连接，本机仍保留结果牌供查看。
- 网络原生验证由两个 API 34 模拟器完成后记录；不把同机模拟器成功扩大为所有实体手机、校园网、路由器隔离或 NAT 情况均通过。

### 应用范围的音效和时间

- 声音按操作语义与材质绑定：普通导航轻静，信封/信笺/贴纸/明信片使用纸张反馈，选择与开关区分，木棋与石棋的落子声只用于棋局。
- 确认音等待实际保存或导出成功，移除音等待删除完成；失败不响完成音。贴纸等父子组件重复包裹的点击声音已经收口到一个边界。
- 当前声音为程序合成的短 Foley 拟音，不是现场实录。设置保留开关和试听；**尚未在实体手机上验听质感与音量**。接线说明见 `feedback-sound-design-2026-10-06.md`。
- 聊天显示的是消息发送时间，不是账单发生时间。首条、相邻消息间隔至少 5 分钟、跨日或时间逆序时插入时间分隔；今天显示时分，较早日期补昨天、星期、月日或年份。

### 玻璃边界和跨应用模糊

- 基础跨应用浮层使用 Android 的局部窗口背景模糊，不为基础模式持续采样。用户后来明确选择新增默认关闭的「全局边缘折射」：只有显式启用并取得本次系统共享授权后，才以最高约 12fps 从整屏共享缓冲复制浮球外侧小 ROI；中心仍是系统模糊。本应用内部保留本应用窗口 PixelCopy 完整折射，不能把二者说成相同效果。
- 可选模式明确显示系统共享标记、静默前台通知和停止入口；采样帧仅内存使用，不保存、上传或识别。拖动、熄屏或停止共享清理缓存；重启仅恢复开启意愿，不自动录取屏幕。完整实现、递归遮罩边界和实测范围见 `global-glass-refraction-2026-10-06.md`。
- 诊断时应查看 SurfaceFlinger 的 `blurRegions`。另一字段 `backgroundBlurRadius=0` 不足以证明局部模糊未工作，也不能为让该值非零而改成整屏模糊。
- Window 背景、View 绘制与 AGSL 使用一致的完整矩形和圆角。去掉只缩小绘制、不缩小平台模糊范围的背景 inset，描边中心线向内收半个线宽，避免透明边带。
- 宿主记录不含用户内容的初始化阶段、平台/回退模式及渲染状态；错误不再静默吞掉。设备主动关闭窗口模糊时使用材质回退，不声称所有 Android 设备都具备相同效果。
