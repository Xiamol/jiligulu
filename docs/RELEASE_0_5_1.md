# 0.5.1 · 等你喝一口

- 喝水到点先保存待办状态，再发送通知。普通闲聊不会覆盖它；退出或重新进入后仍拿杯等待。
- 点通知会回到主界面，点桌宠或喝水气泡进入“举杯、喝水、满足”的动作。动画完成才清除状态；取消则继续等待。
- 气泡改为圆润的不对称轮廓与弧形尾巴；应用图标改为新糯云团，适配自适应图标，通知使用独立水杯小图标。
- 首次引导加入内置键音、声音开关、跳过操作。设置中可试听及重看，预览不会改动称呼和账本。
- 启动和返回应用时，入场动画与本地数据准备并行，正常约 0.8 秒；数据未准备好时继续等，避免露出零金额或空列表。读取失败可重试，不清库。
- 接好 GitHub Releases 检查入口；更新源暂为空，配置后启用，详见 [远程更新说明](UPDATES.md)。

版本号：0.5.1，versionCode：4。Room schema 仍为 v4，没有更改账务表结构；新增状态保存在既有 DataStore 中。

交付安装包：`D:/叽里咕噜/releases/jiligulu-0.5.1-debug.apk`。覆盖安装即可，保留旧账本与偏好。

## 验收路径

1. 开启喝水提醒，返回桌面；提醒出现后点通知，检查咕噜拿杯等待。
2. 等待超过 30 秒、退出再进，杯子应仍在；点击后选“先等等”，仍保留等待。
3. 再点一次并完整看完喝水动作，普通形象恢复，待办清除。
4. 设置中试听键音、重看首次引导；可关闭音效，手机静音模式不播放。
5. 返回桌面后再进入，查看短暂入场过渡；检查旧账和统计保持。
6. 当前没有发布仓库，更新页应显示未设置更新源，不能显示“已经是最新版本”冒充检查成功。

音效为项目脚本合成的原创短键音，没有下载外部录音。源码在 `tools/generate_key_sound.py`，资源在 `app/src/main/res/raw/key_tap_*.wav`。
