# 叽里咕噜 1.3.16 · 比奇堡晴日 🪼

衣橱里来了一群比奇堡的朋友。这个版本也让约棋、翻日历、找常用分类和查看生活圈消息更方便。

[下载 1.3.16 正式安装包](https://github.com/Xiamol/jiligulu/releases/download/v1.3.16/jiligulu-1.3.16-release.apk) · Android 8.0 及以上 · versionCode 76

- **免费领取比奇堡晴日。** 登录后，在装扮小铺打开任一件比奇堡装扮，点「免费答题领全套」。答对海绵宝宝的生日，就能永久拥有主题、聊天气泡、聊天背景和头像挂件。答错后退出试穿页，再进去就能重试。整套无需 VIP 或钻石，之前已买的单件继续可用。
- **透过卡片看比奇堡。** 换上主题后，账本、统计和「我的」主页卡片会透出身后的海水和人物。聊天气泡里的海绵宝宝会挥手、眨眼，挂件上的水母会轻轻浮动。好友页戴上挂件后，照片大小和戴之前一致。
- **联机棋桌。** 下象棋、五子棋时，切换 Wi-Fi、移动网络或关闭 VPN 后，棋桌会尝试接回原局，并补发对方还没收到的棋步。房间号约棋继续使用双方手机直连，建议两位棋友都升到 1.3.16。双方网络限制直连时，仍可能连接失败。
- **统计与日历。** 切换日期、收支或柱线图时，饼图外框保持原位。日历可以左右滑动翻月。在统计页点一次日期选中，再点同一天就能跳转。轻点「收支分布」用月相网格挑月份，长按可转动星盘，两种视图保留同一选择。
- **记账分类。** 对话和手动记账都按使用次数排列普通分类，次数相同的按名称拼音排列，「待定」固定放在最后。草稿或手动记账里缺少合适的分类时，可以就地新建。已保存为待定的账单也可以逐笔选择分类。
- **好友聊天可以拍一拍。** 在私聊里双击自己或好友的头像，头像会轻轻一摇，会话里会出现一条「拍了拍」提示。到「我的 → 编辑资料 → 拍一拍后缀」可以写下自己的后缀。旧版本的好友会收到文字。
- **好友、消息与来信。** 「好友」用于找人看资料，「消息」集中已有会话。生活圈收到的赞、评论和回复会显示互动时间，点开可回到原处。旧记录缺少时间时会显示「时间未记录」。阅读信箱来信时，点左下角的小钟即可按标题翻找旧信。

已有版本请直接覆盖安装，以保留手机上的账本、照片、聊天与设置。也可以打开「设置 → 关于 → 检查更新」获取新版。
