# 操作音效语义与接线核查

日期：2026-10-06。应用源码：`D:\jiligulu`。

## 设计约定

声音跟随操作和对象材质，不根据按钮显示的字推测。普通导航轻静；信封、信笺、明信片、贴纸采用纸张反馈；开关和选择各有统一的声音。棋子落木盘、落石子、吃子和将军只用于棋局，不借给账本页面。

当前 19 类资源是**程序合成的短 Foley 拟音，不是现场实录素材**。以下“材质”描述是设计意图；本轮尚未在实体手机上完成听感验收，不能把代码接线正确等同于扬声器上的质感已经理想。

## 操作 → 材质 / 声音映射

| 语义 | 对应操作 | 声音与触发边界 |
| --- | --- | --- |
| `TOUCH` | 普通轻触、发起保存、发起识别、打开删除确认 | 轻短触感，仅表示点击，不声称成功 |
| `NAVIGATE` | 打开聊天、记账、设置、账单详情，退出一般弹层 | 低存在感过渡声 |
| `SELECT` | 统计收支/图型、日期、时间、分类、皮肤、图案、愿望瓶 | 轻选择反馈；不随滚动或重组反复响 |
| `TOGGLE` | 勾选草稿、收支切换、显示金额、自动分类、收藏/取消收藏、开关设置 | 短开合反馈 |
| `PAPER` | 信封、拆信、写信、收信、翻收藏、贴纸揭取、纪念册、日历翻月 | 纸张轻擦/翻动方向；信封不用敲击音 |
| `CONFIRM` | 数据保存或图片导出成功 | 只在成功结果分支响，不绑定“保存”按钮即播 |
| `REMOVE` | 删除成功、撤销已存记录、取下照片附件 | 轻移除反馈；异步删除失败不播完成声 |
| `CALCULATOR` | 计算器数字与运算键 | 小按键反馈，与普通页面轻触分开 |
| `PET` | 点击常驻桌宠或其台词 | 柔和互动反馈；自动换台词不播 |
| `LAMP` | 场景灯开合 | 灯具开合反馈 |
| `WHEEL_TICK` | 游戏转轮离散刻度 | 有节流的刻度声，不绑定普通页面滚动 |
| `PIECE_SELECT` | 选中棋子 | 拿起/选择触感 |
| `WOOD_MOVE` | 象棋合法落子 | 木质落盘 |
| `STONE_MOVE` | 五子棋合法落子 | 石子落盘 |
| `CAPTURE` | 象棋真实吃子 | 吃子反馈，与普通移动区分 |
| `CHECK` | 真实将军状态事件 | 短提示，只由棋局语义触发 |
| `WIN` / `LOSE` / `DRAW` | 棋局结局 | 胜、负、和各自的有限反馈，不循环 |

`UiSound` 共用缓存池，读取全局启用状态、静音模式和媒体音量。相同语义设有最小间隔；通用轻触与紧随的语义反馈做抑制，但这只是兜底，调用方仍应避免重复包裹。

## 本轮应用页面接线

| 路径 | 已检查 / 调整 |
| --- | --- |
| 主框架、主页、设置入口 | 设置、聊天、记账使用 `NAVIGATE`；打开贴纸墙为 `PAPER`；资料设置行统一导航；主 tab 的导航声由主代理接线 |
| 信箱与未来邮局 | 顶部信封已明确 `PAPER`；邮局对象、写信、编辑、阅读与收起使用纸声；保存成功后确认；实际删除后移除；标记已读不再额外叠一遍成功声 |
| 统计、日历、时间 | 收支和图型选择为 `SELECT`；显示开关为 `TOGGLE`；日历翻月为 `PAPER`、选日/确认时间为 `SELECT`；滚动和图表重算不触发声音 |
| 账单详情、手动记账 | 共用 `LedgerBillRow` 承担唯一导航声，统计调用处删除原有重复声；保存与删除等待 `isComplete` 后分别发 `CONFIRM` / `REMOVE`；完成声有已播放状态保护 |
| 贴纸 | 修正外层 `uiTap` 与 `StickerPaper` 内层 `uiTap` 双重包裹；揭取/编辑/挪动纸声只在组件边界播放；图案/分类为选择，管理/收支为开关；存储成功后确认，实际删除后移除 |
| 愿望 | 瓶子与分类选择为 `SELECT`，回小窝为导航；阅读攒星记录为纸声；存愿望、存候场、攒星在仓库操作完成后确认；删除愿望/撤销攒星成功后移除 |
| 小签与收藏 | 收藏动作改 `TOGGLE`，同时覆盖收藏与取消收藏，不提前播放成功声；翻收藏和收起小签为纸声 |
| 纪念册与海报 | 相册纸页/明信片对象、预览、翻周、收起为 `PAPER`；显示金额为开关、印章为选择；图片实际写入相册/文档或卡片存入纪念册后才确认；删除卡片后移除 |
| 草稿、图片附件 | 勾选/收支/备注展开为开关，分类与时间入口为导航，分类选择为选择；图片选择器纸声；识别填入只是 `SELECT`，不会伪称已入账 |
| 引导与设置子卡片 | 首次称呼真实保存后的确认；动画预览不冒充保存；打字声音/自动更新开关有开合声；重看引导为导航；AI 用量筛选、皮肤为选择；键音试听保留原试听，不叠普通轻触 |
| 共用弹窗 | `GuluDialog` 新增显式 `confirmCue` / `dismissCue`；默认确认仍是 `TOUCH`，调用方按操作选择，避免根据“确认/保存/删除”文案自动推测 |

游戏、网络大厅、主聊天页、场景底座、设置总页及底层 `UiSound` 由并行任务接线；本轮没有覆盖那些文件。音效表中的游戏声音依据现有公共枚举列出，具体棋局事件由游戏任务验收。

## 核查与限制

- 对常用入口逐项读回调，区分“打开操作界面”“改变选择”和“操作成功”，没有加按文案猜声音的通用规则。
- 对本轮修改的 27 个 Kotlin 文件做独立 PSI 语法解析：零语法错误。它不包含类型解析、Android 构建或设备行为测试；统一构建由主代理负责。
- 搜索应用页面没有发现借用木落子、石落子、吃子等棋局声音；保留一般操作的低强度 `TOUCH`，没有给每个按钮分配独特音色。
- 没有在页面滚动、轮播重组、自动刷新台词、图片重绘或恢复列表数据时增加播放调用。异步保存/导出失败分支不播放成功声音。
- 尚未进行实体手机外放/耳机听感比较。后续验收应关注信封是否仍像敲击、快速导航是否扰人、静音是否完全生效，以及异步保存失败时是否误响确认。
