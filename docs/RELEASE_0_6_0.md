# 叽里咕噜 v0.6.0 · 阿噜又学会了新本领 ✨

这次，图片也能变成小账单，翻账本也更顺手啦！

相比 v0.5.6：

- 🧾 **看图记账**：支持选择账单图片，理解红包、转账、订单等收支；结果可修改，确认后才入账。
- 🫧 **悬浮记账**：轻点阿噜截图，长按拖入关闭区可暂时隐藏；图标大小可调，开关和大小都会记住。
- 📖 **按天翻账本**：跟手翻页、日期跳转、收入支出筛选、时间金额排序，还有轻轻的吸附回弹。
- 📊 **统计更清楚**：圆润柱图配上坐标，收入支出联动；分类明细就地展开，预算与分类占比一眼可见。
- 💌 **阿噜的小信箱**：更新消息、节日祝福不用再等安装包，首页下拉就能收取新来信。
- 🌷 **日常小优化**：设置页更清爽，餐次补记更贴心；改善识图重复账单、时间关联与草稿确认体验。

请直接覆盖安装，不要先卸载，以保留本机账单和聊天记录。本次仅提供 release 安装包。
