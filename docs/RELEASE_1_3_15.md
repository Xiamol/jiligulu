# 叽里咕噜1.3.15 · 把小日子照顾得更细一点 🪻

阿噜带着1.3.15来啦 ♡

这次把1.3.14以来的改进一起收进正式版：记账、备份、好友聊天和生活圈更完整，熟悉的手账页面也有了更连贯的动作反馈。

[下载1.3.15](https://github.com/Xiamol/jiligulu/releases/tag/v1.3.15) · Android 8.0及以上 · versionCode 71

## 🧾 账本分得更明白

- 收入按来源、支出按用途归类，补全退款返还、接单收入等收入类别；AI、影音订阅、软件与网络服务等用途分别识别，已有分类和自定义关键词优先复用。
- 手动记账支持自动分类，仍待定的草稿可补充分类建议；新类别先显示在草稿中，确认记账时才建立。分类建议不改动原金额、时间和收支方向。
- 「分类整理」可改名称、识别关键词和合并分类；「升级历史账单分类」先预览建议，再勾选确认。升级应用不会自动替旧账换类。
- 连续对话里的“上一笔”“恢复”“对”等承接更准确，账单修改仍经过操作卡确认。失败保留输入，完成提示对应实际保存结果。
- 年度账单可查看全年收支、结余与分类分布；历史日期浏览、分类明细和预算输入也补齐了恢复与校验。

## 🧳 重要的记录，自己也能收一份

- 「设置 → 数据 → 数据备份」可导出ZIP，在需要时导入本地记录；覆盖前有确认，处理中可查看进度和结果。
- 备份覆盖账本、对话、小记忆、小窝、引用照片、本地游戏、收藏与普通设置等支持的记录。导入以备份文件为准，会替换对应本机内容，请妥善保管文件。
- 登录、注册和游客入口更清楚；可用密码或恢复码找回账号身份。账号找回与本地记录恢复分别管理，找回咕噜号不会凭空找回手机上未备份的账本和照片。
- API密钥、登录密码及系统权限独立管理；装扮权益登录后联网同步，系统权限按需要重新授权。

## 💬 好友聊天，接得住每一句话

- 好友、消息和个人主页的入口更清楚，好友申请、未读状态、后台提醒与返回路径继续完善；消息和好友两栏的设置、回主页面位置保持一致。
- 长按消息先选操作：复制、引用回复，或撤回本人两分钟内发送的消息。文字撤回后可重新编辑，回填后再由你决定是否发送。
- 消息取得服务端接收回执后才显示「未读」；离线投递、送达回执和撤回同步更完整。引用里的原消息被撤回时，对应预览也会更新。
- 支持多张照片和原图选择，大图可在预览中查看；好友管理与个人资料也做了细节整理。

## 📸 生活圈，留住想分享的日常

- 多图、话题、评论、回复与喜欢，配合「全部可见 / 仅自己可见」收好不同心情；发出后仍可调整可见范围或删除。
- 选照片后先预览，可勾选、移除和选择原图，按勾选顺序添加；一篇最多6张，确认添加后先留在草稿，点发布才上传。
- 取消预览保留原草稿和待选状态；部分照片读取失败时，成功项留在草稿，失败项仍可重试。

## 🪄 熟悉的页面，动作更顺手

- 保留首页、统计、对话草稿和手动记账的熟悉排版，完善按钮按压回弹、指尖墨波、页面转场、勾选描线与表单聚焦反馈。
- 设置里的折页、喝水开关和标签拖条连续跟随状态；统计图表、预算进度与生活圈喜欢也有局部联动，系统减少动态时直接呈现结果。
- 聊天新增内容时自然跟随；主动翻看旧消息会保留阅读位置，自己发送后再回到最新。
- 账本里的支付宝、微信入口，在原图标附近展开扫一扫和付款码；长按后左右滑动选择，选项固定，取消与再次按压都能衔接。
- AI服务、影音订阅与网络服务的默认分类图标改为统一线稿，保留个人选用的图标；离开未保存编辑时增加保留或放弃的明确选择。

## 🤝 和阿噜说话，更有回应

- 默认AI连接的等待、截止和取消处理继续完善，失败后可保留原输入再重试。
- 恢复、修改账单时更准确地承接前文，仍由你核对原操作卡并确认。
- 超时和服务错误有更清楚的提示与恢复入口，减少重复等待；联网功能仍需要当前服务可用。

## 安装与使用提醒

- 已有版本请直接覆盖安装，别先卸载或清数据。本版沿用原签名。
- 好友撤回和原图传输请双方升级；撤回同步在对方重新连接并收到消息后生效，无法收回已被复制或另行保存的内容。
- 每张原图最大8MB，保留像素与尺寸并去除隐私信息；超限或格式不支持会明确提示，需由你选择普通画质。大原图传输需要双方在线。
- 离线私聊由服务端加密暂存，最长七天，尚非端到端加密。「未读」表示服务端已接收，不代表对方已经查看。
- 备份请保存在应用外，恢复本地记录前先登录对应原账号。临时未发布草稿不等同于已导出的备份。
