# 1.0.7 本地更新与验收

2026-10-08；versionCode 20。尚未发布新的 GitHub Release，公开下载仍是 1.0.0。

本轮删除七张确认无生产引用的旧图片（14,476,165 bytes），保留当前美术、账本、聊天、照片及棋类模型。详见 [图片与媒体审计](artwork-memory-audit-2026-10-08.md)。安装包体积由 1.0.6 的 144,223,669 bytes 降低；最终安装包 131,598,277 bytes（131.6 MB），减少 12,625,392 bytes；SHA256 `c7dc6ff0dc6264b2d0ec9f218f27fdecd7c0bd500862375a9b53bc44824bf1aa`。源代码提交 `3bd4b60`，签名沿用旧版本。

场景图片的全局强引用缓存限 12 MiB，后台或内存压力时释放缓存引用，可见图片不主动 recycle；冷解码放到 IO。照片解码保持相同目标尺寸和 EXIF 方向，减少中间副本；头像原图经有界临时文件处理，输出 112px/6KiB JPEG；海报串行排队渲染并保证异常清理。Android 29+ 直接读取包内海报字体，避免新增 17,772,300 bytes 临时字体副本，旧系统及现代路径失败保留回退。已有手机数据和缓存未做目录扫删。

同一 API34 QA 模拟器浏览账本、小窝、愿望、邮局、纪念册、互动设置及悬浮拖动的相近路线：旧版含悬浮窗 PSS 169,560 KiB，新版 156,919 KiB（约 165.6→153.2 MiB）；原生私有堆 79,560→66,584 KiB。另一账本返回采样为 151,215→149,429 KiB。属于单次开发环境采样，页面字体缓存、额外演示数据、GC 及设备均会影响结果，不承诺真人手机同样降幅。原始 dumpsys 记录在 output/android-qa/oct8-memory。

## 功能与边界

- 每笔已生成草稿都有独立夹照片入口，收起和展开均可用。生活照不送识图或模型；持久保存后再释放导入 claim，保存期间暂停确认。确认后与账单、纪念册关联；清空聊天后只重查并释放无保留引用的旧草稿照片。
- 明确身份和喜好的常见自述可在本地记录，不依赖模型的可选记忆字段或在线成功。临时做饭或做家务不自动当成职业。Boolean compare-and-set 只推进本请求写入的 revision，清空、禁用或更正不会被迟到回复复活。
- 设置中可选 3/7/30/90 天或全部账单范围，默认 3 天。各档明细上限 30/100/300/600/1000，约 48K 字符预算，截取会写入模型说明；精确查询不限这些范围。个人小记忆与账单上下文是独立功能。
- 统计图内即时选择 5/7/10 天或整月，缺省整月；紧凑窗口严格在同一月内，首次触边回弹，第二次同向拖动定位相邻月首窗/尾窗，当前手势剩余位移和惯性不会继续移动新月。箭头、日历和选中日期同步。预算下可记忆切换月/年已过比例。
- 主导航为账本/统计/小窝。缺省系统刷新率、手帐拼贴、音效开启、15/s 采样；旧用户已保存选择保留。
- 局内玻璃拖动恢复动态采样，并按当前坐标重投影有效裁剪；边缘和透明度保持稳定，不反复淡入。静态没有周期性刷新。局外保留透明材质，未恢复跨 App 屏幕采样。主动启动应用结束旧截屏共享；Android 必需的悬浮服务通知保持静默，主动截图仍遵守系统授权。
- 房间代码保留原始 TextFieldValue，仅提交时规范化；选择、删除、覆盖和 IME composition 可用。支付宝/微信扫码付款入口并排，支付宝左侧。支付宝 intent 限定自身 package，失败才试同包备用 scheme；系统接收 intent 不等于已经进入目标页，需要对应手机版本确认。
- 名片相册头像经能力协商后独立分块传输，不放大棋局的 1024-byte 帧限制；坏图片、拥堵、超时只降级头像，不退出棋局。详见 [头像协议](room-avatar-protocol.md)。
- 心事寄给阿噜后通过当前供应商生成独立回信，进入未来信箱并沿用到信提示。发送在应用 scope 内最多 90s，关闭编辑器不取消已发送任务；失败可重试、回复幂等，模型返回的账单/命令不会执行。小六壬按公开月日时顺数规则独立实现，只用于娱乐，保留阿噜印章玩法。
- 删除可从外部或返回关闭的纯关闭按钮，保留保存、发送、删除及真实对局选择。顺手修复时间滚轮开窗自动偏移两格；确认、取消和初始/边界值回归均覆盖。

## 验证

公开构建参数 publicRelease=true；全量 testDebugUnitTest 921 项通过，无失败、错误或跳过，最后的临时行为守卫再跑 21 项相关回归全部通过，assembleRelease 与 lintVitalRelease 通过。Robolectric 使用已缓存的 API28/API35；API34 模拟器真实运行验证草稿选图→确认→生活照片、明确自述 0→1 条持久记忆、统计首尾跨月、预算按钮真实点击、海报字体及拖动录屏。临时中文剪贴板 QA helper 无任何权限，仅装在自有模拟器，验收后卸载。

重开 Dialog 后的最终按钮在 Robolectric 中用无障碍语义激活验证；busy 与外部关闭仍使用真实 MotionEvent。实际 Android 预算确认另做物理点击验证。心事与头像协议采用独立 FakeHTTP/FakeWire，不产生付费请求；本轮没有重新验证真人跨设备互联网连接和手机上的支付宝目标页。相册头像另在模拟器完成选择与名片保存验证。

主要原始截图与录屏在 `D:/叽里咕噜/output/android-qa/oct8-memory/` 和 `output/android-qa/screenshots/memory-*.png`。存储截图中的“应用/数据/缓存”是磁盘分类，不是进程 RAM；应用包含安装包与展开资源，数据包含持久用户内容及模型，缓存包括临时图片和字体等，也不同于供应商的提示词缓存命中率。
