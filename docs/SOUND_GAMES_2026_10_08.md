# 1.0.3 音效与棋桌验收

日期：2026-10-08（Asia/Tokyo）；版本 1.0.3 / 16。本地测试包，GitHub App 公开版仍为 1.0.0。

## 音效

- 根因之一：UiSound 使用媒体游戏通道，却在铃声静音/振动时提前退出。现只跟随媒体音量和应用音效开关；不修改手机音量，不抢音频焦点。
- 五子棋落子增益 .32→.45；每次有效落子播放一次，取消 85ms 通用节流，快速同屏落子不再丢音。选中反馈略提亮。
- 全部 34 个 WAV 完整，无全静音、削顶、长静默开头；UiSound 的 29 个资源与轮换样本均有效。落子声原本较轻，资源并未损坏。
- 信箱上一封/下一封、转盘进入邮局/纪念册与星座入口、计算器切换编辑方式补齐符合动作的声音。
- 键音跟随媒体音量；喝水声遵守应用音效开关，音量降低，不再绕过关闭设置。
- 五子棋回前台不补播旧结算；象棋快速应手等待已经落定的将军声，不抢先取消。
- 保持装饰入口无专属提示音，辅助落子沿用正常落子反馈。

## 和棋

- 房间/附近的象棋与五子棋将“认输”入口替换为“和棋”。请求期间暂停协商，接受才结束为平局，拒绝/撤销继续原局；双方同时请求视为双方已同意。
- 求和使用独立 nonce、round、revision；防迟到、重复、跨轮请求和未同意的假平局。拒绝或撤销不会重置剩余思考时间。
- 后台/恢复、重复连接与重发结果保留原棋盘，不生成非法普通平局快照；对方离开按原逻辑提示。
- 普通象棋 STATE 不允许 DRAW；求和只通过明确的双方同意控制消息结束，既有非法输入断言保留。
- 协议升级 XQ2/GO2，附近发现版本 4，**双方需使用 1.0.3 或更新版本**。初次握手失败提示确认版本，不武断把其它网络失败归因于版本。
- 结算居中“和棋”，不伪造杀法，配平局声；再来一局与房间寿命保持原流程。

## 五子棋搜索

- 修复后备评分固定按白方计算，改按当前执子方；另修候选邻域的 Kotlin buildList size 接收者遮蔽，保留 15/19 路旧局兼容。
- 原创 Kotlin 增量棋盘、精确开放四/跳四/活三与边缘判断，全盘战术扫描、连续冲四证明、对手连续冲四防御、包含所有合法防手的连续活三证明；主搜索用 PVS、置换表与强制延伸。
- 普通人机每步最多 1200ms，较强分析场景最多 5000ms；都在后台线程，退出、局面变化与求和协商取消。预算结束返回已完成候选，用户取消返回 null，不提交过期着法。
- 14 项新回归包括长强制线、主动阻断对手连续冲四、双活三遭远处反四、边缘假活三、远处必防、中心/角落邻域、取消与原棋盘不变。不是穷尽搜索，也不保证战胜所有真人。
- 参考 [Rapfi 的搜索原则](https://github.com/dhbloo/rapfi/blob/master/Readme.md)与[战术分层](https://github.com/dhbloo/rapfi/blob/master/Rapfi/search/movepick.cpp)；没有复制 GPL 源码、导入网络权重或新增原生库，继续完全离线，无额外 API 费用。
