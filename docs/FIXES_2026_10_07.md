本地测试包，尚未发布为 GitHub 正式版。

## 对局

- 同屏直接悔棋，无额外确认。象棋分别「悔红／悔黑」，五子棋分别「悔黑／悔白」；撤回所选方自己的落子及随后的回应，连续悔棋同样处理。
- 在线悔棋仍需对方同意。后台或连接恢复期间暂停协商倒计时，防止已同意但延迟到达的结果导致断局。
- 等待房间保留 5 分钟；临时后台通知对方暂停，提供最多 5 分钟恢复窗口。显式退出关闭房间，系统杀进程后的跨进程续局暂不支持。
- 两种棋增加认输，防止旧回合、错误身份的请求改写结果；处理认输与同时落子的竞态。
- 在线数据增加消息确认、重复过滤和未确认操作重放，恢复连接不重新随机棋色。
- 直接点击转盘开始旋转，结果位置固定；等待匹配时隐藏未开局的回合与时钟。

## 记账

- AI 可以提出按日期、关键词、分类的只读检索，数据库查询所有未删除历史账单，再给 AI 真实结果回答。
- 汇总覆盖全部匹配记录，明细最多 45 笔；没有命中就说明没有查到，不再拿最近三天代替。
- 查询与改账意图区分，修改草稿只能使用本轮提供的账单 ID。检索通常比普通聊天多一次请求，固定前缀继续复用。
- 长按「待定」打开批量重新分类：DeepSeek 每批最多 30 笔，先预览和勾选，确认后只改分类；金额、时间和照片保留。被编辑、删除的账单和被删除的目标分类会安全跳过。
- 新增水果、蔬菜、通讯、运动、旅行、礼物预设及稳定图标。保留同名自定义分类，补齐一次后不会重新添加被用户删除的预设。

## 设计与验证

[可编辑 Figma 设计](https://www.figma.com/design/ky0Q8dxbC9RA07vKE9rg6f)包含对手选择、房间与附近匹配三页。字体沿用 Noto Sans SC 与站酷快乐体；奶油纸张、淡紫雷达、单行房间码和水彩邀请签。Figma 中的棋友名字仅为排版演示，App 只展示实际发现的棋桌，不虚构距离。

生图使用内置 imagegen，参考现有阿噜形象；最终独立素材为 `app/src/main/res/drawable-nodpi/game_room_invitation.png`。设计提示词与概念图在工作区 `output/matchmaking-design-20261007`。

- Release 构建和必要的 lint 检查通过；657 项单元测试全部通过。
- JavaScript 传输测试通过：操作去重、重连身份、缺失消息排序、35 秒连接截止及关闭清理。
- 凭证接口测试通过：coturn HMAC、有效期、独立身份、不返回共享密钥与配置检查。
- Android 模拟器运行核对入口、房间、雷达、转盘、同屏按钮与手动分类。

## 尚待完成的流量跨网验收

旧 PeerJS 内置的免费 TURN 中继已停服；房间注册成功不能证明 WebRTC 数据通道已连接。当前只有 STUN，运营商 NAT 下依然可能无法直连；加入等待已设置截止并给出明确错误。

已提供 [中继部署文件和验证步骤](../server/chess-relay/README.md)。部署有效 TURN 和短期凭证接口，填写 `relay-config.json` 的 HTTPS 地址后，还需要两个不同网络设备实际对局验证。未经部署与跨网验证，不将这项标为完成。
