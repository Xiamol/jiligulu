# 1.0.8 本地更新与验收

本地构建 versionName 1.0.8 / versionCode 21，沿用签名，覆盖安装保留账单、照片、聊天、设置和游戏。GitHub 当前公开版本仍为 1.0.0，本轮没有发布新的 Release。

## 改动

- 悬浮玻璃在页面上下、左右滚动时保留最近有效材质，再交接新采样，避免每个页面帧都清空纹理。首次从长时间静止进入滚动也有交接时间。异步结果仍校验窗口和位置，连续复制失败只保留有界时间；静止没有周期采样或到期轮询。局外仍为透明材质，不采集其他 App。
- 设置「互动 → 悬浮与玻璃 → 悬浮常驻通知」直达原有通知类别。Android 不允许应用自行关闭已存在的通知类别；用户在系统页关闭一次即可隐藏这条常驻消息，悬浮球继续运行。邮件、喝水提醒和主动截屏类别独立，系统悬浮/活动应用提示不受此设置控制。[Android 通知类别](https://developer.android.com/develop/ui/compose/notifications/channels)
- 记忆理解个人问答中的短回答，支持性别、年龄、生日、学校、校区、年级等。只从用户本人说的话提取；阿噜的猜测和「记住了」不构成事实。第三人资料和金额问句终止旧的本人资料问句。年龄数字不生成金融操作或额外检索；真实的同金额待补账单不会因自述年龄消失。
- 旧用户可在「互动 → 阿噜的记性 → 补记聊天资料」预览、勾选本地历史中的明确资料。只读取开头和最近各 128 条正文，不加载整段历史或调用模型。自动迁移不恢复曾删除的记忆；关闭、删除、更正与确认补记均校验资料版本。
- 小六壬先填写问题，再选此刻或三位数字。此刻法保存当地日期、农历月日、时辰和时区；三位数字法保留原数，本版 0 按 10 计。原盘本地算出，AI 结合问题解读，失败时有本地说明。保存结果并最多缓存 16 份解读，重看不重复收费。星座与小六壬改命独立各每日一次。[起课约定](xiao-liu-ren-rules.md)
- 心事回信只弹出到达提示，「去邮局」进入完整未来邮局场景。到达提示不显示正文、不标已读，之后手动进入收件箱查看。
- 主页气泡同时清理句首及冒号后的多余逗号，不再显示「说：，名字」。
- AI 服务增加每日费用堆叠柱图、用途颜色、累计、单日 token 与费用明细、供应商/模型筛选和单价设置。记录实际 HTTP 尝试及返回的用量，费用为当时配置单价估算，不能视为服务商实扣。重试单独计次、同请求 ID 不重复记录；缺用量、缺缓存字段或未配置价格保留未知。旧汇总不套用当前价格重算。仅保存元数据，不记录消息、照片、URL 或密钥；图表与累计使用 SQL 聚合。[计价约定](ai-cost-meter.md)

## Android 页面验证

使用拥有的 Android API 34 模拟器（1080×2400）运行发布构建，保持网络关闭，不调用用户的收费 API。不是物理手机测试。

- 固定悬浮球位置，回放相同的账本上下滚动及左右滑动，保存修改前后原始录屏并逐帧检查。修复过早清空材质导致的明暗交替；此验证不承诺零采样延迟或所有设备均同帧刷新。
- 在系统类别页隐藏「阿噜悬浮记账」后，通知栏没有该条消息，前台服务及悬浮球仍运行。系统显示的「正在其他应用上层显示」是独立系统提示。
- 回放「你知道我是男生还是女生吗 → 男生 → 你猜我多少岁 → 19 → 19岁 → 年龄纠正 → 生日2月28」；设置显示性别、年龄和生日，原大学生资料保留，没有新年龄账单。历史补记预览不重复相同资料。
- 小六壬问题与三数 137 完整走通；离线解读保留问题与三宫。切回此刻法显示实际农历月日时。小六壬改命后星座按钮仍可用。
- 临时虚构回信只显示到达弹窗，点「去邮局」先出现全页场景，手动点收件箱后才出现信件。
- 35 条明确标为虚构验收数据的费用元数据展示七日分色、累计与单日各 token 部分；验证后恢复原信箱字节并仅移除临时费用条目。未使用真实 API 花销作为演示。

另外，实际删除演示生日后，预览补记显示该候选；点「记下所选」后弹窗关闭，资料恢复到四条。费用图的日期居中对应柱子，日选择由图表统一处理，避免 30 个放大的点击区域挤偏日期。
