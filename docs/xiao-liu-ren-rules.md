# 小六壬起课与解读约定

先保存用户这一问，再由用户选择当前农历月日时，或自己想到的三个数字。计算时保存本地时区、时间戳、农历月日、时辰及原始报数；重看和跨午夜均不重新起课。盘是本地确定性计算，AI 只结合问题解读已有落宫。

采用六宫顺序“大安、留连、速喜、赤口、小吉、空亡”，每一段的起点都计为 1。三位数字逐段顺数，本版本明确选择 **0 按 10 计**。这是报数的一种约定，不声称所有流派一致。闰月沿用该月号，23:00–00:59 为子时，日期仍取本次问占的当地公历日期，不采用晚子时自动加一天。

规则核对来自作者自己的公开仓库：[kev1nzh37/liuren](https://github.com/kev1nzh37/liuren)、[Sneezry/XiaoLiuRen-MCP](https://github.com/Sneezry/XiaoLiuRen-MCP)、[mxwz 的三数计算](https://github.com/mxwz/astrbot_plugin_zhanbu/blob/main/xlr.py)。0→10 的报数约定对照了[国学居作者的工具说明](https://www.guoxueju.com/shushu/liurensuduan.html)。仅核对规则，未复制这些项目的代码、签文、解释或美术。

农历转换使用 Android 平台 [ChineseCalendar](https://developer.android.com/reference/android/icu/util/ChineseCalendar)。公历日期在中国标准时中午转换，避免设备时区让日期漂移；本地时辰由保存的起课瞬间计算。回归日期以香港天文台 [2024](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2024.pdf) / [2025](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2025.pdf) 年历核对。

## 三宫解读（1.0.9）

原实现只核对了起课算法。本地降级文案实际只使用末宫，联网提示虽提三宫，却没有限定阶段与转折，因此不够完整。本版删除旧通用签句，采用明确的应用解读约定：**起点 → 过程 → 趋向**，三个位置都对应用户问事，再解释两次相邻转折。不是所有流派统一的断法，也不是大六壬的四课三传。

三段展示参考 [Li-xianyu/bazi-skill 的说明](https://github.com/Li-xianyu/bazi-skill/blob/main/SKILL.md)，但该项目的属性与道传扩展不混入本版。六宫属性核对 [Sneezry 的六神表](https://github.com/Sneezry/XiaoLiuRen-MCP) 和 [mxwz 的六宫实现](https://github.com/mxwz/astrbot_plugin_zhanbu/blob/main/xlr_shi.py)，固定为大安木、留连土、速喜火、赤口金、小吉水、空亡土。代码与解读文字独立编写，没有复制这些项目的提示词或断语。

相邻五行完整区分同属性、前生后、后生前、前克后、后克前。关系有方向，元素相同才是比和；留连与空亡虽同属土，宫意仍不同，不能直接解释为顺利。同宫重复也保留三个不同位置，分别看准备、推进、落实。

例如问明天面试：报数 `223` 为留连→速喜→小吉，解释应围绕准备/安排反复、沟通消息推进、一次具体小进展；`364` 为速喜→留连→小吉，虽末宫相同，先后为消息到来、等待反复、最后小推进，不能使用同一段末宫文案。相邻关系也分别解释，不能凭最后一个“小吉”保证录用。

联网输入包含原问题、原三宫、阶段角色、属性与已计算的两个相邻关系。输出分为总览、三个阶段、两次联系与实际建议；逐位校验原问题、原宫、原关系与长度，拒绝缺段、乱序、泛泛无题材、保证断语等。界面原宫和关系来自本地，模型不能改动。仅这些解读字段可显示，不执行返回的账单、记忆或导航。

单次联网解读不自动购买重试或格式修复；不合格、空内容和请求失败均展示明确的「本地三宫简析」，用户主动选择才再请求。正常对话记账原有重试策略保留。联网任务由应用持有，限时 50 秒，换课取消旧任务。计量归入“小六壬分析”。

解读最多保留 16 份，每份结构数据最多 2400 字符。缓存版本升级为 v4，旧泛句不再作为已完成解读显示；起课快照与改命状态保留，打开旧课不会自动多花一次费用。缓存键绑定规范化问句、方式、实际来源和原三宫；时间法含日期、时区及闰月，报数法含原三数。精确秒数只用于展示，同课重看不新收费，不附账本与历史聊天。

星座运势沿用旧 `rewritten_day`，小六壬独立保存 `liuren_rewritten_day`，各自每日一次。趣味盖章只添一句鼓励，保留真实计算的原始三宫。

这是民俗娱乐，不作结果保证，不能替代现实决定。界面问号中提供说明，不在每一步堆放提示。
