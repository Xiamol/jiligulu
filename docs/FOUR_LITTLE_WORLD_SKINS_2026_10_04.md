# 小窝四款皮肤

2026-10-04。用户选择将四个设计方向全部内置，并在设置里切换。版本保持 0.6.2 / 12，本次交付本地 Release 预览包，未发布 GitHub。

## 使用

设置 → 日常 → 外观 → 小窝皮肤：月光星瓶、手账拼贴、草莓奶油、森林邮局。

四张缩略图直接点选，立即自动保存，不需要再点底部“保存设置”。新安装默认手账拼贴。用稳定的枚举 ID 存入 DataStore，未知值回退默认；页面读取期间不先显示错误的默认皮肤。点选后立即返回也不会取消已开始的偏好写入。

## 实现与布局

- 沿用此次内置 image_gen 生成的四张透明 PNG，复制到 drawable-nodpi 的 world_skin_* 资源，保留原始透明度；无需联网下载。
- 小窝底色随皮肤变化，边框位于没有触控行为的背景层。给内容留出边角位置，账单时光机卡片按底角装饰方向左右错开，避免遮住星瓶或信封。账本/统计页面功能维持原有行为。
- 主页面使用原图分辨率，选择器使用 1/4 采样缩略图；统一在 IO 解码。按图片字节数限制为 16 MiB 的 LRU 缓存，无常驻动画，也不在拖动期间反复解码。
- 删除已替换的 LifeGardenCornerDecor 原生花角代码。
