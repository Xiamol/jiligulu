# 0.6.2 本地预览：整页小世界、棋桌与消费预测

此批为本地预览，未发布 GitHub。版本保持 0.6.2 / versionCode 12，沿用原签名。

## 最终行为

- 未来邮局、生活纪念册、时光列车和秘密基地使用整页场景。点击邮袋、邮筒、旧信匣、相册、照片架、列车或车票打开原有功能；内容窗口保留滚动弹簧和滑条。
- 小窝的电子计算器画面替换为传统木算盘。背景插画统一降低饱和度，不处理用户照片和金额语义色。
- 下拉秘密入口与长按品牌入口分别有木门和星光动画。灯、挂星、小纸条和阿噜的睡觉状态可交互；游戏或页面离开前台会停止本地动画、计时和 CPU 任务。
- 贪吃蛇、固定 15 路五子棋、象棋使用整页。象棋先生成设计参考，再以原生 UI 实现：上方正中共享钟形倒计时仅显示秒数，模式与回合一行，按钮独立，不含两个玩家信息框。五子棋棋盘在页面中间。
- 本地象棋开局可设置每手思考秒数并记住选择，时间到可继续，不判负；暂停和后台停表。人机、同屏、LAN、互联网房间均可用，联机目前不限时。选中、可走点、可吃子、最近一步和对方选中有不同提示；含三种一步取胜小残局及不同棋子庆祝效果。
- 隐藏落子辅助：在棋桌右下角阿噜装饰上四秒内连续点七次，用本地增强搜索替当前真人走一步。回合文字只用于显示。没有新增文字提示、按钮或 Toast；象棋展示正常选子后落子，联机沿用普通合法落子协议。暂停、离页、后台、改局、换模式或打开弹窗取消待执行步骤。增强搜索采用 850 ms / 64k 节点上限、象棋迭代加深与吃子搜索、五子棋威胁搜索；不调用 API，不宣称专业引擎或绝对最优。
- 小算盘改成最大 284 dp 宽的底部面板，缩小结果和标题、减少间距；数字键仍至少 48 dp 高，方便单手输入，计算与精确金额逻辑保持原样。
- 每日收支卡片切换柱图 / 整月折线。柱图保留五日横滑；折线全月同屏，实际和预测可独立勾选，点日期联动分类分布。今天的实际金额标“截至现在”，未来实际为空。
- 消费预测全部本地计算：最近 28 个完整日、至少 7 日历史、指数平滑、保守星期混合、正金额中位数 / MAD 上限减弱偶发大额；历史点只使用当时之前的数据，当前月预测到月末。混合策略为自建启发式，金额用约数表示；收入只展示实际。
- 四种皮肤同时改变纸张印纹、卡片边缘、形状、色彩和少量水彩装饰，设置选择立即保存。底部导航缩为 58 dp，图标 22 dp，保持点按和拖动切换；信封图标在数据加载时也保留。

## 性能与玻璃

子页面的大图按需在 IO 解码，移除未使用旧场景的启动预载。绘图复用背景刷、文字画笔和缓存木纹，游戏 CPU 在后台计算并核对局面；网络选中提示合并，棋局消息优先。

悬浮图标未显示时不注册玻璃的逐帧绘图监听；重建图标时重新绑定当前窗口。

API 33+ 的悬浮玻璃在本软件 Activity / Dialog 上通过 PixelCopy 和 RuntimeShader 做真实背景采样、边缘折射及轻色散。拖动后在移窗完成时刷新并合并最后一次请求；后台、关闭和窗口切换移除待处理任务，不跑空闲循环。在其它软件上使用系统模糊、边缘和光泽回退，不能读取其它软件的实时像素；没有为了玻璃启动持续录屏。

## 验证证据

使用两个 AOSP API 34 安卓模拟器，1080 × 2400 / density 420。账单、照片和信笺为明确虚构的 QA 数据，不调用记账 AI。

相关 98 项单元测试通过：贪吃蛇 / 五子棋 17，象棋规则 21，LAN 协议 8，棋局同步 3，选中提示 5，本步时钟 6，残局 1（覆盖三个局面），消费预测 6；另含主页吸附 5、导航手势 2、统计日期 5、金额轴 1、增强搜索 9、隐藏触发 3、十进制计算器 6。发布构建和 release vital lint 通过。

原生操作已验证：固定 15 路落子与 CPU 回手；贪吃蛇转向 / 暂停；象棋合法落子、CPU 回手、残局取胜、共享计时重置和暂停停表；LAN 和互联网两实例红黑落子及双向选中提示，落子清除提示；互联网重开和短暂后台返回；整月预测、开关、日期联动、收入切换和柱图返回；三个目的地的内容入口、周明信片、算盘计算；两类秘密入口动画、睡觉 / 唤醒和小灯；四种皮肤的原生页面变化及保存。

联机证据来自同一电脑的两个原生安卓实例：互联网通过公共 PeerServer / WebRTC 建房和交换数据，LAN 通过模拟器虚拟 Wi-Fi 直连。没有将此测试描述为已覆盖两台物理手机、所有跨网 NAT 或长期公共服务可用性。API 34 模拟器用于布局及交互验证，不据此承诺实体设备帧率。
