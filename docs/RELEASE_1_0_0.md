# 叽里咕噜 1.0.0 · 阿噜搬进小窝啦 🏡

阿噜来啦！这次带来的不只是一页小账本，还有一整个可以坐坐、玩玩、收藏生活的小窝 ♡

这是相比上一正式版 **0.6.2** 的一次大更新。

## 新住进来的小伙伴

- 🏡 **小窝成为第三个主页面**：账本、小窝、统计可以点按或跟手滑动切换，场景中的物件就是功能入口。
- ⭐ **星星愿望瓶**：给小愿望攒一点点钱，看瓶子慢慢装满，完成后留下自己的纪念。
- 💌 **未来信箱**：写给未来的自己；在路上的信、收件箱和旧信匣都有自己的场景。
- 📸 **生活纪念册**：账单可以夹照片，回忆可以做成明信片与海报；今日小签、收藏纸条和时光列车也来报到啦。
- 🎨 **四款全局皮肤**：小装饰、配色和页面一起换心情，选择会被记住。
- 🎲 **小游戏与小彩蛋**：象棋、五子棋、贪吃蛇、转盘，陪阿噜坐下来玩一会儿；还有夜景与睡眠互动等你发现。

## 小账本也长进了

- 手动记账更紧凑，支持自动分类、夹照片与小算盘；聊天草稿更容易找到金额、分类和时间，消息支持选择复制与交谈时间分隔。
- 整月折线与每日柱图切换，实际金额、日均参考、分类占比和预算更好看清；分类先高亮，再点打开明细小窗。
- 微信扫一扫与付款码快捷入口，可调大小和记住位置的悬浮图标；全局折射需单独授权，默认关闭。
- 优化 AI 请求前缀缓存、历史读取和响应，新增本机用量与费用预估。日常请求关闭思考模式，费用与命中率以实际请求为准。

## 玩起来，翻起来，更顺手

棋盘放到大页面，选子与落点更明确；支持悔棋、每回合计时、人机、同屏双人、附近棋友和互联网房间。走子有动画，象棋结算按实际终局展示将死、闷杀、重炮等水墨字样，淡出后再询问是否下一局。

重新整理滑动回弹、吸附保持和底部导航拖动；修复多余空白、切页闪动、长按删除继续清空、动画中悔棋卡住及旧结算重复出现。小窗、按钮位置与操作音效也做了调整。
