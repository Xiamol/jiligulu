# 阿噜的小世界：场景与操作融合

本地预览，2026-10-05。版本保持 0.6.2（12）。没有发布 GitHub。

## 界面

- 小窝使用完整房间场景。瓶架、信箱、桌上的相册、算盘、签筒、时光列车和阿噜都有实际点击区域。名字印在画里的挂签上，原来的四张普通功能卡片移除。页面高度适配可用空间。
- 愿望册中正在攒、候场、纪念是柜子里的木牌。只有实际愿望才摆瓶子，九个一架。点击瓶子查看小窗，添加、编辑、攒星记录、候场购买记账、照片与海报入口保留。
- 未来信有送信、收件箱、旧信匣三个场景，点画中物件可读信。写信和切换木牌在场景内部。
- 纪念册用书脊、装订环和纸页呈现照片与明信片，原来的“照片票根”改为“生活照片”。先看照片，再主动打开账单。
- 时光列车有独立站台，点列车从最近 300 笔实际记录涉及的旧日期中随机选一天，也可选车票日期。
- 小窝顶端第一次下拉提示，2.6 秒内第二次足量下拉进入秘密基地。主标志长按也能进入。基地提供八格生活小转盘、20 秒接星星和十二张纸条，睡觉/醒来状态保存。游戏在离开页面或后台时停止，没有后台动画循环。

## 设置与浮窗

- 四个皮肤沿用原偏好键，扩展到全局颜色。收支语义颜色保留。名字、称呼后缀和 API Key 单独弹窗保存，总保存栏删除。
- 公告已读、选择不再弹出均移除未读角标，跨重启保存；手动仍可读旧公告。
- API 31+ 浮窗使用独立窗口的局部背景模糊，加上透明吉祥物、移动边缘高光与按压形变。不支持系统模糊时保留高光玻璃外观。没有持续录屏读取背景，也不声称实现苹果的光学折射。
- 背景与小道具共享图像缓存；大场景保留原分辨率，小道具采样。删除旧小窝首页不再展示的日常账单查询。
