# 0.5.0 · 奶油手账

## 已实现

- 使用已确认的奶油手账风格：内置中文正文字体、品牌字、分组账单、温柔便签与新的糯云团资源。桌宠顶部常驻，约每 10 秒换句，点击立即回应。
- 账本与统计共用账单行和详情面板。金额、名称、日期及时间都可修改，保存后统计与列表更新。统计增加独立的日期筛选。
- 手动记账支持补记日期。对话没有明确时间时按确认入账时刻记录；“昨天中午”等明确时间按请求时设备时区解析；缺具体日期时提示选择。
- 聊天记录、编辑草稿、确认/取消/中断状态保存到 Room，退出页面与应用后可以恢复。旧版没有写入磁盘的对话不能追溯恢复。
- 确认草稿时，时间、分类、全部账单和确认状态一起提交；失败回滚，重复确认不重复记账。
- 设置页增加糯云团互动、便签、版本号与字体许可说明。
- Room v4 提供 v1/v2/v3 的安全迁移，保持包名和数据库文件名。没有清库重建兜底。

## 安装与验收

安装 `app/build/outputs/apk/debug/app-debug.apk`，版本号 `0.5.0`，versionCode `3`。请覆盖安装现有应用，不用卸载重装或清除应用数据来更新。

可按以下路径验收：

1. 更新前记住几笔旧账及预算，覆盖安装后核对仍存在。
2. 在账本点一笔账，把名称、金额和日期改掉；到统计选择对应日期，再打开同一笔核对。
3. 对话输入“昨天中午吃饭花了9块”，检查草稿日期是昨天、时间为 12:00；确认后查昨天账单。
4. 输入“早餐9元”，不手动选日期时应按确认入账的此刻记录；退出对话再进入，消息和确认状态保留。
5. 输入“9月买电脑100元”这类缺具体日的描述，应先选择日期，不能悄悄记到今天。
6. 设置中检查浅色/深色、昵称、喝水偏好、页面底部的版本号。
