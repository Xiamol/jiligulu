## 可以做些什么

- **记账与统计**：手动输入、对话记账、图片识别；草稿确认后入账。分类、预算、收支图表和小计算器，够日常使用。
- **收好生活**：给账单夹照片，制作明信片，收藏小纸条，写下愿望，寄一封给未来的信。
- **阿噜的小窝**：不同主题、白天与夜晚，还有象棋、五子棋、转盘等小玩法。
- **和朋友来往**：个人主页、好友聊天、生活圈、棋局邀请。装扮可以先试穿，再决定是否使用。

基础功能可以一直免费使用。装扮、会员及自愿支持各有说明，不打赏也照常使用默认功能。未成年人请不要打赏。

## 安装前知道这些

已有版本请覆盖安装，先别卸载或清数据；本机账单、照片和聊天不会因账号找回而自动恢复到另一台手机。

基本记账和部分本地玩法可离线使用。象棋已内置，无需另装；五子棋采用按需组件，首次下载后可离线玩，卸载组件会保留棋局存档。AI、好友、生活圈及权益操作需要网络和可用的服务。付款目前由开发者人工核对，请按应用提示备注咕噜号；付过款但没有备注，可以在订单里反馈。

## 它是怎样运行的

手机端使用 Kotlin、Jetpack Compose 和 Room，账本、照片及本地记忆主要保存在手机上。在线功能由开发者的电脑运行 Node.js 服务，通过 Sakura 隧道连接互联网；默认 AI 请求由电脑转发，也支持用户自行配置兼容服务。

这是个人维护的应用，电脑休眠、断网或隧道维护时，部分在线功能会暂时不可用。它目前没有整库自动云同步；账号找回与本机资料备份是两件事。

调用 AI 会发送本次问题及所需的文字、图片或账本上下文；发布生活圈或发送好友消息，也会把对应内容发送给在线服务。具体范围见应用内说明。
