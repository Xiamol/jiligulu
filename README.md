# 叽里咕噜 · 阿噜的小生活家 🪻

一只会陪你记账、收好回忆的糯云团。聊天记一笔，夹一张生活照片，再去阿噜的小窝坐坐。

**1.3.16 · Android 8.0及以上**

[下载安装](https://github.com/Xiamol/jiligulu/releases/tag/v1.3.16) · [本次更新](docs/RELEASE_1_3_16.md) · [反馈与建议](https://github.com/Xiamol/jiligulu/issues)

新版衣橱里的「比奇堡晴日」可以免费答题领取。答对一次，就能永久拥有主题、动态气泡、聊天背景和头像挂件。

- **把账记清楚**：文字、账单图片、手动填写与悬浮截图，先整理草稿，确认后入账；分类、预算和年度账单帮你慢慢看懂收支。
- **把日子收起来**：愿望瓶、未来信箱、生活纪念册、小签和收藏，给喜欢的瞬间留个位置。
- **和朋友说说话**：按咕噜号加好友，聊文字、照片、表情，也能引用回复、撤回消息、邀请对局；生活圈收好日常与回应。
- **换个心情歇一会儿**：多款皮肤与小窝、象棋、五子棋、贪吃蛇和好运转盘，阿噜都在这里陪你。

已有版本请直接覆盖安装，保留账单、照片和设置，别先卸载或清数据。完整使用手册在「设置 → 关于」；本地记录可在「设置 → 数据 → 数据备份」导出，账号找回与本地备份分别管理。

基本账本、小窝和本地游戏可离线使用。AI识别与对话、好友和生活圈需要网络及可用服务；AI可在设置中选择DeepSeek或自定义兼容供应商。你提交给AI的文字、图片与必要上下文会发送给所选服务，识别结果由你确认。好友私聊支持签名与离线投递，尚非端到端加密。

公开仓库保留历史源码，当前应用主体和电脑服务未整体开源。美术、字体和第三方组件分别适用各自许可；个人配置与账号数据不随更新发布。

慢慢记，日子也会慢慢发光。阿噜陪你把普通的一天收好 ♡
